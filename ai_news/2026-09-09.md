1. **主推工具動態／資安｜Claude Code v2.1.265發布：Cowork／Desktop遙測新增使用者信箱與群組欄位，另補上外掛資料夾管理與1GB結果上限**
   新聞內容：Anthropic於9/8發布Claude Code v2.1.265。核心變更包括：讓Claude Desktop與Cowork透過Claude apps gateway回傳的遙測資料，新增`user.email`與`user.groups`兩個欄位，使其行為與終端機（CLI）session的遙測一致；新增`--plugin-dir`旗標，可指向一整個外掛資料夾，其中每個含有manifest的子資料夾都會自動載入，且執行期間新增/移除外掛也會被即時偵測；工具執行結果落地磁碟時新增1GB上限，超過時對話內會顯示「已截斷」提示。此外本次也修復了「resume前景生成的子agent時，工具清單與系統提示前綴被改變、導致prompt cache失效」「並行worktree checkout在大型repo上效能不佳」等多項穩定性問題。
   為什麼對我們有意義：對IT／資安團隊而言，`user.email`與`user.groups`被納入Cowork／Desktop遙測，代表未來若稽核或申請資料存取紀錄時，可透過gateway取得更細緻的「誰在用」資訊，但反過來也代表更多可識別員工身分的資料會經由Anthropic的gateway傳輸，需要重新檢視這是否符合公司個資處理與員工隱私政策；對程式團隊而言，`--plugin-dir`讓管理整批內部自製外掛（例如美術規範檢查、企劃文件範本技能）更方便統一部署與版本管理。
   建議後續：IT／資安主管確認Cowork／Desktop遙測新增的員工信箱與群組欄位是否已納入公司個資盤點清單，必要時知會法遵；工程主管可評估將現有分散在各專案的自製Claude Code外掛集中放進單一資料夾，以`--plugin-dir`方式統一管理與部署。
   來源：GitHub Release（https://github.com/anthropics/claude-code/releases/tag/v2.1.265）；X／ClaudeCodeLog（https://x.com/ClaudeCodeLog/status/2097429227125477449）

2. **主推工具動態｜Google Antigravity CLI v1.1.28發布：修復CPU異常飆升至32%的顯示錯誤，強化API逾時重試與啟動速度**
   新聞內容：Google於9/9（今日）發布Antigravity CLI v1.1.28。主要修復「當任務面板或子agent詳細面板開啟時，介面會持續重繪、導致處理程序CPU使用率被拉高到約32%（正常應僅約10%）」的效能錯誤；同時強化對暫時性模型API錯誤（如503 Unavailable）的容錯能力，改為以指數退避（exponential backoff）方式重試更長時間，避免agent因暫時性錯誤而提早失敗；並改善登入與啟動速度（改讀取本機已儲存的憑證，不再每次啟動都對外發送網路請求驗證身分）。
   為什麼對我們有意義：若工程團隊已在日常開發或CI流程中使用Antigravity CLI，這次修復直接處理了「長時間開啟任務面板導致本機CPU被不必要占用」的資源浪費問題，對筆電效能與電力續航有感；API重試機制強化則讓agent在雲端服務暫時不穩定時更不容易無故中斷任務，減少工程師需要手動重跑的次數，對長時間跑批次重構或測試的場景尤其有幫助。
   建議後續：已導入Antigravity CLI的工程團隊可於本週升級至v1.1.28，並留意長時間開啟任務面板時本機資源使用率是否確實恢復正常。
   來源：GitHub Changelog（https://github.com/google-antigravity/antigravity-cli/blob/main/CHANGELOG.md）；GitHub Releases（https://github.com/google-antigravity/antigravity-cli/releases）

3. **成本情報｜Claude Fable 5.1快取讀取價格砍75%，Anthropic估算重度agentic工作負載最多可省45%成本**
   新聞內容：Anthropic於9/1發布Claude Fable 5.1與Mythos 5.1（本頻道9/6已報導其在Cursor Bench的效能表現，本則聚焦先前未報導的定價變動）。官方將Fable系列的快取讀取（cache read）價格由每百萬token 1美元大砍75%至0.25美元，標準輸入／輸出定價則維持每百萬token 10美元／50美元不變，快取寫入仍為5分鐘快取12.5美元、1小時快取20美元（每百萬token）。Anthropic表示，由於agent類任務經常反覆把相同的程式碼庫、系統提示、技術文件送進模型當作上下文，快取命中往往占長任務token用量一半以上，此次調整預期能讓一般工作負載成本降低約25%，重度agentic工作負載最多可降低約45%。
   為什麼對我們有意義：若公司已大量使用Claude Code或Cowork處理長時間、多輪來回的agent任務（例如大型重構、跨檔案除錯、長篇企劃文件迭代），這類任務正是快取讀取占比最高的場景，此次降價對實際帳單的影響可能比單純的輸出token降價更明顯，財務／IT採購單位若先前用「輸出token」為主估算月費，應重新用「快取讀取占比」重新試算。
   建議後續：IT財務窗口請1名工程師抽樣近一個月Claude Code／Cowork帳單，估算快取讀取token占比與新舊價格下的實際月費差異，作為下季度AI預算重新編列的依據。
   來源：Anthropic官方部落格（https://www.anthropic.com/claude-fable-and-mythos-5-1）；VentureBeat（https://venturebeat.com/technology/anthropics-claude-fable-5-1-and-mythos-5-1-arrive-with-a-75-cost-reduction-for-fable-cache-reads）

5. **GitHub趨勢／工具能力（程式／企劃）｜開源技能「Archify」爆紅衝上5.6萬星，一句話把程式碼結構變成可互動架構圖**
   新聞內容：開發者tt-a1i於GitHub釋出的開源agent技能「Archify」，讓Claude Code、Cursor、Codex CLI、OpenCode等coding agent只需依使用者描述的系統或直接掃描程式碼庫，就能產出架構圖、流程圖、時序圖、資料流圖、生命週期圖共5種圖表，輸出為內建互動效果、可切換深色/淺色主題的獨立HTML檔案，也可匯出PNG、SVG、WebM或社群分享卡片；技術上採用「先產生型別化JSON中介表示、再經過驗證檢查」的作法，避免圖表憑空畫出程式碼中不存在的依賴關係。安裝方式為單一指令`npx skills add tt-a1i/archify -g`。專案8月底才約4,200星，短短一週內即登上GitHub Trending第一名，截至查證時已衝上約5.6萬顆星，作者也曾在X上分享自己從保全、修車工、工廠作業員一路到多次被科技公司拒絕錄取的背景故事，帶動大量二次轉發。
   為什麼對我們有意義：對程式團隊而言，這類工具能快速把既有（尤其是缺乏文件的）遊戲後端或工具鏈程式碼自動轉成一目了然的架構圖，大幅降低新人上手或跨團隊交接的說明成本；對企劃室而言，也可用來把系統設計描述直接轉成視覺化流程圖，用於企劃文件或向處長簡報系統架構，且因輸出是自成一體的HTML檔案，方便直接分享而不需額外軟體開啟。
   建議後續：工程主管可指派1名工程師在既有專案（尤其是文件不足的老舊模組）試裝Archify，評估產出圖表的準確度與是否可納入新人onboarding流程；企劃室同步評估能否用於系統企劃文件的架構圖產出。
   來源：GitHub（https://github.com/tt-a1i/archify）；X／wolfdeng（https://x.com/wolfdeng/status/2055702845052363062）；KuCoin新聞快訊（https://www.kucoin.com/news/flash/github-trending-tool-archify-automates-architecture-diagrams-with-ai）

6. **GitHub趨勢／資安（QA／工程）｜開源AI滲透測試agent「Strix」衝破6萬星，自動找漏洞並驗證可行的攻擊證明**
   新聞內容：開源專案「Strix」（Apache 2.0授權，github.com/usestrix/strix）是一套多agent協作的自動化滲透測試框架，能對網頁應用、API與程式碼進行偵察、漏洞利用、驗證的完整流程，涵蓋OWASP Top 10（權限控管缺陷、注入攻擊、XSS、SSRF、認證/session缺陷、API資安漏洞等），且強調「只回報真正能被利用、附帶可執行概念性驗證（PoC）的漏洞」以降低誤報率，並可直接整合進CI/CD與GitHub Actions、針對OpenAPI/Swagger規格做API測試、輸出可交付的修復建議與合規報告。今年7月初單日狂漲逾2,137顆星登上GitHub Trending第一，9月初持續發布v1.6.2等版本強化agent生命週期管理與雲端平台功能，目前星數已突破6.1萬顆；科技創作者Avi Chawla稍早在X發文以「一個開源AI agent複製了要價2萬至5萬美元的傳統滲透測試服務」為題，引發大量轉發討論。
   為什麼對我們有意義：公司若有官方商城、儲值/金流串接或玩家帳號系統等需要定期資安檢測的服務，傳統委外滲透測試往往要價數萬美元且耗時4-6週才能拿到報告，Strix這類開源自動化pentest agent提供了「內部工程/資安團隊自行、更高頻率地做初步資安掃描」的低成本選項，尤其適合在每次上版前先做一輪自動化掃描、抓出明顯的OWASP等級漏洞，再視需要委外做更深入的正式滲透測試。
   建議後續：資安／工程主管可指派1名工程師在非正式測試環境（勿直接對正式環境掃描）試跑Strix，針對官方商城或後台管理系統做一次自動化掃描，評估其誤報率與PoC品質，作為是否納入上版前例行資安檢查流程的參考。
   來源：GitHub（https://github.com/usestrix/strix）；X／Avi Chawla（https://x.com/_avichawla/status/1994305031974342832）；Strix官方（https://www.strix.ai/open-source-pentesting）

7. **工具能力（程式）｜RavenDB發布Quill：免遷移直接讓AI agent串接既有企業SQL資料庫**
   新聞內容：資料庫廠商RavenDB於9/8發布新產品「Quill」，是一套架在既有SQL資料庫之上的「情境層（context layer）」，讓企業不需將資料庫遷移到新系統、也不用自建客製AI技術堆疊，就能讓AI agent直接對PostgreSQL、SQL Server、MySQL等既有正式環境資料庫進行搜尋、檢索與agent操作，同時仍保留原資料庫作為系統唯一真實來源（system of record）；官方表示可依資料主權或法規需求選擇雲端或地端（on-premises）部署，並宣稱能將「AI agent導入正式環境」的時程從傳統18-24個月的自建專案，縮短為數週。RavenDB創辦人暨執行長Oren Eini表示：「任何人都能在一個下午做出AI demo，但要把demo做到正式上線——資料管線、語意搜尋、資安、治理，這些小型概念驗證用不到、但要規模化運作就一定要有的『管線工程』，才是真正困難的部分。」
   為什麼對我們有意義：對程式團隊而言，若公司的玩家資料庫、金流紀錄、營運報表等核心系統多半架構在既有SQL資料庫上，這類「免遷移」的情境層可大幅降低讓Claude Code／Cursor等agent安全存取正式資料庫做查詢分析、客服工單比對、營運報表產出的技術門檻，不必為了導入AI而重新設計一套資料架構；相較於自建管線動輒18-24個月，這也提供了一個評估「buy vs. build」時程與成本的具體參考基準。
   建議後續：工程主管可請1名資深工程師在測試環境資料庫（切勿直接串接含玩家個資的正式庫）試評估Quill的存取治理機制與部署模式，若地端部署選項符合公司資安要求，再評估納入下一輪內部BI/客服工具建置的技術選型清單。
   來源：GlobeNewswire官方新聞稿（https://www.globenewswire.com/news-release/2026/09/08/3357703/0/en/ravendb-launches-quill-to-bring-production-ai-agents-to-enterprise-sql-systems-no-migration-required.html）；HackerNoon（https://hackernoon.com/ravendb-launches-quill-to-bring-production-ai-agents-to-enterprise-sql-systemsno-migration-required）
