# Chat On Steroids 白話說明

> 給不想看技術細節、只想知道「這工具是什麼、能不能用、怎麼用」的人看
> 完整技術版見 [chat-on-steroids-資安評估-2026-09-15.md](chat-on-steroids-資安評估-2026-09-15.md)

## 這是什麼工具

讓你在 ChatGPT 網頁對話裡，直接指揮你的電腦——叫它讀某個檔案、幫你跑一段程式、甚至操作桌面畫面，不用自己開終端機動手做。等於幫 ChatGPT 裝了一雙手一張嘴，能碰到你的電腦。

## 資安評估：三件事決定你要不要用

1. **這台電腦只要有其他壞程式，等於幫它也開了門**
   這工具認證方式是「只要是你這個使用者身份跑的程式，都算自己人」，沒辦法分辨「是我本人在用」還是「電腦中毒後、病毒冒充我在用」。所以只裝在自己乾淨、信任的電腦，不要裝在公用電腦或已經懷疑中毒的機器。

2. **「讓它自己下指令」這個開關，一開就等於把終端機交給對話內容**
   工具裡有個進階功能可以讓 ChatGPT 直接執行系統指令，預設是關的。一旦打開，風險就變成：如果 ChatGPT 讀到的檔案或網頁裡藏了一段「騙術文字」，它有可能被騙去執行你不想要的指令（這叫 prompt injection）。除非真的需要，這個開關建議保持關閉。

3. **安裝檔沒有官方簽章，下載時要自己核對**
   目前版本 Windows 沒有微軟認證簽章、Mac 也沒有蘋果公證，理論上壞人可以做一個假安裝檔騙你下載。裝之前要去官方 GitHub release 頁面核對檔案雜湊值是否一致，不要隨便從其他連結下載。

**一句話結論：** 工程做得算用心（基本防護都有），但骨子裡是「同一台電腦上大家互相信任」的設計，加上一個「可選但很危險」的執行指令功能——只在自己乾淨的電腦上用、進階功能能不開就不開，就是合理的用法。

## 使用情境

**適合的情境**
- 你主要用 ChatGPT（不是 Claude 或 Codex），想直接在網頁聊天視窗操作本機專案檔案、跑測試，不想切換到另一個工具
- 團隊已有 ChatGPT Developer Mode／自訂 MCP apps 權限，想用既有 ChatGPT 額度做「本機代理人」
- 個人裝置上做輕量、低機敏度的雜務，且清楚知道要保持「自動執行指令」關閉
- **用量／額度考量**：它不是另外算錢的獨立服務，而是直接吃掉你 ChatGPT 帳號本身的對話用量與額度（官方註明「使用你的 ChatGPT 對話，而非另外呼叫 Codex」，且 ChatGPT Work 與 Codex 共用同一個用量上限）。適合「本來就有 ChatGPT Plus/Team/Enterprise 額度、想物盡其用」的人；若拿它跑長時間、會不斷來回讀檔案/跑指令的任務，會比單純聊天更快把當月額度用完，評估導入時要把這筆「額度消耗」納入預期成本

**不適合的情境**
- 公司電腦、共用電腦、或已有其他不明軟體的裝置
- 處理機敏原始碼或客戶資料的專案——它不是官方產品，出問題沒有原廠支援管道
- 團隊已在用 Claude Code 或 Codex CLI/Desktop 做開發——功能重疊，多裝一套等於多開一個攻擊面，卻沒換到明顯新能力
- 需要長時間、高頻率自動化跑本機任務（例如當背景常駐 agent 持續監控/處理）——會很快把 ChatGPT 額度耗盡，且因與 Codex 共用同一額度池，可能連帶排擠原本用 Codex 的用量

## 跟 Claude Desktop、Codex Desktop 比較

| | Chat On Steroids | Claude Desktop | Codex Desktop（OpenAI） |
|---|---|---|---|
| 官方／第三方 | 第三方，靠瀏覽器擴充套件掛在 ChatGPT 上運作 | Anthropic 官方 | OpenAI 官方 |
| 本機能力來源 | 自建 Electron app + 瀏覽器擴充套件橋接 | 官方 MCP 協定，自行安裝設定 MCP server | 原生內建，不需額外擴充套件 |
| 終端機／檔案操作 | 有（含可選的任意指令執行） | 需另裝第三方 MCP server 才有終端機控制 | 原生內建，持續加深功能 |
| 信任模型 | 同機信任（任何本機程式都能冒充） | 同樣本機執行，但每個 MCP server 在應用內有清楚授權設定 | 官方原生產品，安全更新走正式管道 |
| 適合對象 | 想用 ChatGPT 網頁對話操作本機的人 | 已用 Claude 生態、想按需求疊加 MCP server 的人 | 已用 ChatGPT/Codex 生態做正式開發的人 |

**一句話比較：** Claude Desktop 和 Codex Desktop 的本機操作是原廠親自做、有官方支援；Chat On Steroids 是幫 ChatGPT「外掛」出一套本來沒有的能力，工程用心，但出事沒有原廠兜底。

## 簡報大綱：每段白話三重點

### 開場｜為什麼看這個案例
1. 這是一個讓 ChatGPT 直接操作本機電腦的工具，用的人可能不少，值得先搞懂風險
2. 檢查方式是把原始碼下載下來實際讀過，不是只看官方說明
3. 目標：搞清楚「能不能裝」「裝了要不要開進階功能」

### 問題說明
1. 基本防護有做（指令執行、檔案存取都有把關），比一般同類工具用心
2. 但「同一台電腦上的人都算自己人」是設計上的取捨，不是修得掉的漏洞
3. 「自動下指令」這個進階功能一開，等於把終端機交給對話內容，可能被騙去做壞事

### 我們該怎麼做
1. 只裝在自己乾淨、沒有其他不明軟體的電腦上
2. 安裝前核對官方雜湊值，避免裝到假安裝檔
3. 只開放真的需要的資料夾，「自動下指令」能不開就不開

### 檢查清單（這些防護機制有做到）
1. 執行指令用安全的方式做（不是直接把字串丟給系統執行），避免被塞入額外指令
2. 檔案存取有邊界檢查，防止跳出被核准的資料夾範圍
3. 本機連線有做驗證，不是隨便一個網頁或程式都能呼叫

### 結尾｜一句話總結
1. 工程上把信任範圍設計得算嚴謹，但骨子裡仍是「同機信任」
2. 進階的自動執行指令功能，權衡風險後再決定要不要開
3. 只在自己乾淨的裝置上、限縮授權範圍後使用，是合理的用法
