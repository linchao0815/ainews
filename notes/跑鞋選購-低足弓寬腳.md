## 1. 我的腳型數據

| 項目 | 數值 |
|---|---|
| 足長 | 26.5 cm |
| 足寬 | 10.5 cm |
| 寬長比 | 39.6%（一般約 37%） |
| 推估寬度級別 | 約 JIS 3E（EEE），最保守也是 2E |
| 足弓 | 低足弓 |
| 趾型 | 二趾較長（希臘腳／Morton's toe） |
| 目標 | 全馬 sub-3:20（4:44/km） |

**症狀**：跑步後小趾、四趾常出現黑指甲。

### 待確認事項
- [ ] 足寬 10.5cm 是**坐著**還是**站著（承重）**量的？低足弓承重時前掌會再外擴 0.3~0.5cm。若為坐姿量測，實際跑動寬度可能接近 11cm → 屬 **4E** 領域。
- [ ] 做一次步態分析，確認是真的過度內旋，還是只是低足弓但力學正常。
  - 過度內旋 → 買支撐型鞋
  - 力學正常 → 買中性鞋 + 支撐鞋墊（會更舒服）

## 2. 問題診斷

三個條件疊在一起，指向同一個問題：**跑動中的前掌橫向空間不足**。

- **二趾較長**：腳的最長點不是大拇趾。傳統鞋楦從大拇趾就開始往內收，二趾會頂到鞋面斜面。
- **小趾／四趾黑指甲**：這是前掌**外側**被壓，**不是長度不夠**。問題在鞋頭的**寬度 + 垂直高度（側邊斜度）**。
- **低足弓**：承重時足弓塌陷、前掌外展變寬 → **站著試穿覺得「剛好」，跑起來一定太窄**。
- **全馬**：30km 後腳會腫脹將近半號。

26.5cm 足長的標準 D 楦大約對應 9.8~9.9cm 足寬 → **我比標準寬約 0.6cm**。這就是黑指甲的成因，已不需再猜。

## 3. 選鞋規格（硬性條件）

必要條件：
- ✅ 寬楦（US 2E 起 / 日規 3E 起），或本身鞋型就超寬的品牌
- ✅ 方頭／解剖式鞋型（不能從大拇趾就開始收窄）
- ✅ 鞋頭要有**垂直高度**，不只是寬度
- ✅ 導引式支撐（GuideRails / J-Frame / 中底外擴 / 內高外低），**不是硬支撐柱直接擠壓足弓**
- ✅ 高緩震（撐得住 42km）

### ⚠️ 最重要的一條
**不要用「買大一號」來解決寬度問題。** 長度加大半號只多出 1~2mm 寬度，補不上缺的 6mm；而且鞋子變太長會造成腳前後滑動，反而製造新的黑指甲。**寬楦版本是必要條件，不是加分項。**

### 寬度換算（方向性參考，需實測驗證）
JIS（日規）和 US 寬度不是同一套刻度，粗略對應：

| 我的腳 | 對應標示 |
|---|---|
| JIS 約 3E | ≈ **US 2E（Wide）** |
| | ASICS 日規 3E ≈ ASICS US 2E |

NB 在中國市場賣的標準版本身就是 2E。**所以「US 標示 2E」很可能就夠了，4E 不是硬門檻。**

足長 26.5cm + 最長趾是二趾 + 全馬會腫脹 → **鞋內需 27.5~28.0cm**

## 5. 買鞋前的驗證法

### 抽鞋墊踩測試（10 秒判掉八成不合的鞋）
1. 把鞋墊整片抽出來，放地上
2. **光腳站上去**（要承重，低足弓這步關鍵），腳跟對齊鞋墊後端
3. **前掌左右有沒有溢出鞋墊邊緣？** 溢出 → 直接淘汰，不用穿
4. 二趾前端到鞋墊前端要留 1~1.5cm

### 鞋頭高度檢查
手指壓在小趾正上方，如果立刻頂到鞋面 → 淘汰。這是四趾／小趾黑指甲的直接元凶。

### 其他試穿原則
- 下午或跑完步後試穿（腳處於腫脹狀態）
- 穿比賽用襪試穿

## 7. 大陸品牌調查結論

### ❗ 核心結論：大陸品牌沒有任何一雙 4E

這是結構性的：國產品牌普遍只開**單一寬度鞋楦**，不做 2E/4E 寬度分級 SKU。ASICS、NB 在同一尺碼提供標準/2E/4E 三種楦頭，國產品牌基本沒有對應做法。

**國產鞋的上限大約是「2E 等效」**，而且都是評測者主觀對比，不是實驗室實測數據。

### 可用清單（依對症程度排序）

#### 🥇 361° 國際線 Phoenix 2 — 唯一有官方 Wide 2E SKU
唯一同時滿足「大陸品牌 + 官方寬度分級 + 明確低足弓定位」的鞋。
- 361° 是廈門品牌，但**國際線**（361usa.com / 361europe.com）走歐美規格，有 **D 和 Wide 2E**
- 官方定位直接寫：**低足弓、扁平足、過度內旋跑者**
- 雙密度中底（Primo Foam + ENGAGE Foam）+ 底基加寬 + 後跟外擴
- 評測對標 **ASICS Kayano 31**，促銷價約 400+ RMB

#### 🥈 必邁 遠征者 5.0 / 6.0
- 前掌寬度**接近 ASICS 2E 楦**

## 8. sub-3:20 的配置建議

3:20 = **4:44/km**。決勝點是訓練量和 30km 後不崩。以 3E 寬腳 + 低足弓的條件：**鞋子合腳的邊際效益遠大於碳板。**

碳板超級鞋大約給 2–4% 的跑步經濟性。但 30km 起黑指甲加前掌水泡，掉的遠比 4% 多。

| 用途 | 建議 |
|---|---|
| **訓練（80% 里程）** | 361 Phoenix 2 (Wide 2E)、必邁遠征者 6.0，或國際線的 Kayano 32 (3E) / Topo Ultrafly 6 |
| **節奏跑 / 馬配** | 361 飛燃 5 **MIX** |
| **比賽日** | 國產只有飛燃 5 MIX 一個選項。更保險 → **ASICS Magic Speed 2E Wide** |

## 9. 不換鞋也能改善黑指甲的做法

1. **足跟鎖定綁法（heel lock / lace lock）** ← 免費，單一改善幅度最大
   - 用最上方那個額外鞋孔做繞圈綁法固定後跟
   - **前掌鞋帶反而放鬆**
   - 腳不往前滑是關鍵
2. **指甲**：比賽前 3 天剪好，**平剪不要剪圓弧**（避免嵌甲），平常 3~4 週剪一次
3. **襪子**：薄、無縫、排汗。厚襪會直接吃掉鞋頭空間
   - 五趾襪對趾間摩擦有效，但會增加**橫向厚度** → 橫向壓迫的問題可能反而更糟，要自己試
4. **鞋墊**：低足弓可加 Superfeet / Currex RunPro Low / Sidas
   - ⚠️ 鞋墊會吃掉鞋內容積，選尺寸時要一起算
5. **下坡**：全馬下坡段縮短步幅、提高步頻，減少腳往鞋頭衝的衝量

## 10. 醫療警訊

撞擊造成的黑指甲會**隨指甲生長往外緣移動**。

如果出現的是**單一條縱向黑線**、沒有明確撞擊史、而且長期不退也不隨指甲往外移 → **請看皮膚科排除甲下黑色素瘤**。這種情況少見，但不該自己猜。

## 11. 資料來源與研究限制

### 研究限制（重要）
- **知乎、42k.tools、361usa.com、日本 JIS 對照表網站在查詢時被網路代理封鎖**，部分數據是透過搜尋引擎摘要取得，非讀原文

- 結論：**國產鞋的寬度數據可信度明顯低於國際品牌，必須自己實測，不能照數字下單**
