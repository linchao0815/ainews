週末最火的 4 大神級 Mod 應用：
1. 防刪庫保命鎖（Safe-Guard）：0.01 秒攔截 rm -rf、drop table 與強推 main 分支，比寫提示詞可靠一萬倍。
2. 測試守門員（TDD Enforcer）：只要 Unit Test 或 Lint 沒全綠，外掛直接禁止 AI 宣告完工，自動把報錯塞回去叫它重修。
3. 金鑰隱形斗篷（Secret-Masker）：上傳雲端前自動把 .env 密碼換成遮罩代號，本機自動還原零外洩。
4. 語意提交官（Semantic Git）：自動掃描 Diff 產出標準 Commit 與 PR 報告。
