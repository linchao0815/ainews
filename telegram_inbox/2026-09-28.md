🧭 Paperclip 把 OpenClaw、Codex、Claude Code 等 agent 放進同一個控制台。README 直接寫了個場景，例如一次開 20 個 Claude Code 終端：誰在做什麼開始記不住；電腦重開，工作脈絡又斷掉。

⚠️ 我會在意這類工具，因為麻煩常在 agent 跑起來後才出現。能暫停、回查、看清成本，比再多開一個終端實際。

他用 Opus 5.5 跑同一類工作來看差異。模糊需求「做一個健身紀錄 App」，low 大約 1.5 分鐘，只做出紀錄表和簡單圖表；medium 4 分鐘、high 11 分鐘；max 67 分鐘，功能更完整，還多了一張熱力圖。需求越含糊，檔位越高就越會自己補細節。另一個例子是重設 Claude Code 的 /config 選單：low 1 分鐘交出能看懂方向的互動草圖，max 28 分鐘做出很接近真實介面的樣稿，還附操作流程。需求先講清楚再實作時，各檔做出來的東西會比較接近，但時間仍差很多：16、22、33、79 分鐘。
