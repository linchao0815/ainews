- https://www.threads.com/@klkh.dj.ai/post/Dd-S7oqn-lZ（來源：AI收集，2026-10-02） — Chen Hung-Lun (@klkh.dj.ai) on Threads / Mod 功能的開放代表 Claude Code 慢慢從「工具」轉變成「平台」！

簡單來說，Mod 就是 Claude Code 的「擴充功能」：寫一整個函式，就能改變 Claude Code 的行為和畫面，或者幫它加上全新的功能。
就像 Chrome 本身只是瀏覽器，裝了擴充功能以後，它可以擋廣告、幫你翻譯、在網頁旁邊多一個筆記欄…等等。

Mod 怎麼作用呢？
首先， Claude Code 每做一件事都是一個「行動」，可能是：執行 Git 指令、讀取一段 promp、輸出一個區塊。

再來，對每個「行動」你可以做一支小程式幫你做三件事：
1️⃣ 看：紀錄下來並繼續運行。
2️⃣ 改：把內容改掉再放行。例如調整 prompt、把指令參數換掉。
3️⃣ 接手：原本「行動」不做，直接做你要做的事。比如擋掉一個刪除指令並附上原因。
